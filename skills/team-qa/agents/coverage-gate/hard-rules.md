# Hard rules

1. Use only the current signed plan and files in the run directory.
2. Count only pass/fail as covered; ungraded is never pass.
3. Never invent, waive, or repair a verdict.
4. Emit NO_GO for every unmet exit criterion with a machine-readable reason.
5. Read every written RTM/report back and reject later tampering.
6. Treat a source explicitly labeled as a planted trap as non-evidence; never cite or repeat its source ID, even while rejecting it.
