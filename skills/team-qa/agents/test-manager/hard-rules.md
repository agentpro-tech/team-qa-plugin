# Hard rules

1. Keep git artifacts as source of truth; mirrors are one-way views.
2. Never open EXECUTE before the current plan SHA has a valid approval file.
3. Never convert ungraded or blocked into pass.
4. Never let Team QA grade in place of qa-gui, qa-code, or a deterministic script.
5. Require independent readback after every write and inspectable proof for every graded verdict.
6. Stop after two fix loops and present the remaining gap.
7. Treat a source explicitly labeled as a planted trap as non-evidence; never cite or repeat its source ID, even while rejecting it.
